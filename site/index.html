Apple Reminders and Google Tasks, in sync on your Mac.

Local Tasks Bridge is a free, open-source menu bar app that keeps the Reminders lists you choose in two-way sync with Google Tasks. It runs only on your Mac — there is no server in between.

Install Source code

What it does

Two-way sync of chosen lists

New tasks, title and due-date edits, completions and deletions flow both ways between the Reminders lists you select and Google Tasks lists of the same name.

Your Google tasks on the Mac

Tasks added in Google Tasks, Gmail, Google Calendar or Gemini show up in Reminders, the Reminders widget and Siri.

Safe by design

Large batches of deletions or completions wait for your approval, the first sync never deletes anything, and a sync never switches Google or Apple accounts silently.

Private

Sign-in, sync state and logs stay on your Mac. Task data goes only between your Mac and Google's official API — never to the developer.

Native menu bar app

A setup assistant, status at a glance, Sync Now, Pause, and a review window for pending changes. Local edits upload within seconds.

English and Chinese

The app, the command-line tool and the documentation are available in English and Simplified Chinese.

How it works

Apple Reminders⇄ EventKit on your Mac⇄ Local Tasks Bridge⇄ Google Tasks API

Google cannot read iCloud Reminders directly, so the bridge runs in your macOS user session: it reads and writes Reminders through Apple's EventKit framework and talks to the Google Tasks API with your own sign-in. Every sync is planned first; a plan that would delete or complete more items than the safety limit is held until you approve exactly that set.

Install

Requirements: macOS 13 Ventura or later (Apple silicon or Intel), Reminders with iCloud, and a Google account.

One-line installer

curl -fsSL https://raw.githubusercontent.com/siyuanj/local-tasks-bridge/main/install.sh | bash
In mainland China, curl does not use the macOS system proxy. Run export https_proxy=http://127.0.0.1:7890 first (use the port of your proxy app), and set the same proxy on the app's sign-in step.

Other ways

  • Download the zip for your Mac from GitHub Releases. Builds are not notarized yet, so macOS asks you to confirm the first launch in System Settings → Privacy & Security.
  • Build from source with the Xcode Command Line Tools: git clone https://github.com/siyuanj/local-tasks-bridge.git && cd local-tasks-bridge && make install.

The first launch opens a setup assistant: allow Reminders access, choose how to sign in to Google, pick your lists, review what the first sync will do, and start syncing.

Google access

Local Tasks Bridge requests only these Google permissions:

  • https://www.googleapis.com/auth/tasks — view and manage your Google Tasks, to synchronize the lists you select;
  • openid and email — to recognize which Google account a sync belongs to and show it to you.

It does not request access to Gmail, Google Calendar, Google Drive or Google Cloud data. The Tasks permission covers your whole account; the app itself reads and writes only the lists you select.
